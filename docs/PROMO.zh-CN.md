# 中文宣传文案

## 标题

接上下一步。写清你的指令。｜dsh-next-step

## 一句话介绍

给 DSH 加上输入框灰字建议和一键提示词优化：Tab 接受建议，魔法棒优化草稿，发什么由你决定。

## 发布正文

给 DeepSeek Harness 做了一个插件：**dsh-next-step**。

回复结束后，它会根据最近的对话，把下一条消息的建议以灰字显示在输入框里。按 **Tab** 变成草稿，还能继续修改；按 **Esc** 忽略，也可以直接写自己的消息。

已经有草稿？点击输入框工具栏的**魔法棒图标**，就能优化表述。模型会收到保留原意、语言和明确约束的要求，结果填回输入框，由你检查、修改，再决定是否发送。失败时保留原稿，等待期间的新输入也不会被迟到的结果覆盖。

两项功能都不会自动发送消息。支持桌面端和 Web 端，沿用 DSH 已配置的模型与凭据，不用另填 API Key。

启停统一在 **DSH 插件管理**中操作：启用 dsh-next-step 即可使用，停用插件即可关闭。输入框里只有操作图标，没有独立的“下一步”开关。

生成建议和每次点击优化都会额外调用模型，正常消耗对应服务的额度。

[源码、安装与演示](https://github.com/Tieboyh/dsh-next-step) · [下载与视频](https://github.com/Tieboyh/dsh-next-step/releases/tag/v0.3.0)

## 短文案

给 DSH 加了两个小功能：

- 灰字建议下一条消息，**Tab 接受，Esc 忽略**。
- 写好草稿，点**魔法棒**优化提示词。

结果都可修改，不自动发送。桌面端和 Web 端可用，启停统一在插件管理里操作。

[源码与安装](https://github.com/Tieboyh/dsh-next-step)
