## 标题

下一步，按下 Tab。｜dsh-next-step

## 一句话介绍

让 DSH 把下一步建议写成输入框里的灰字。Tab 接受，Esc 忽略，发什么由你决定。

## 发布正文

做了一个 DSH 小插件：**dsh-next-step**。

每次回复结束，它会根据最近的对话，给出一条可能有用的后续指令，直接以灰字显示在输入框里。

想用就按 **Tab**，变成草稿后还能继续改；不想用就按 **Esc**，或者直接输入自己的消息。插件不会替你发送。

支持桌面端和 Web 端，沿用 DSH 现有的模型与凭据，不用另填 API Key。输入框旁有开关，随时可以关闭。

生成建议会额外调用模型，消耗对应服务的额度。没有合适的下一步时，也可以不显示建议。

源码、安装说明和演示：
[github.com/Tieboyh/dsh-next-step](https://github.com/Tieboyh/dsh-next-step)

## 配图说明

1. 灰字直接显示在输入框内，尚未写入草稿。
2. 按 Tab 接受后，变成可继续编辑的普通文字。
3. 改好再发送；最终指令仍由你决定。
4. 按 Esc 忽略，回到空输入框。
